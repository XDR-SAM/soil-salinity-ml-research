# Source provenance

- The mounted instruction was the only research input in the empty workspace. Both workbooks were retrieved from the specified Zenodo versions. Both MD5 values match the expected hashes. The data manifest records independent SHA-256 values. [2024 workbook record](https://zenodo.org/records/14560019) · [2025 workbook record](https://zenodo.org/records/19711551)
- The workbook header is on Excel row 3. The only populated non-field row beneath either header is the copyright footer. Both records use the same extraction and meter. The source descriptor’s broader March 1–9 window differs from the March 2–6 dates actually entered in the workbook. [Scientific Data descriptor](https://doi.org/10.1038/s41597-025-05447-1)
- The optical extraction used native pixels, scene classification codes 4 or 5, and asset-specific scaling and offsets. The study uses Collection-1, which carries explicit scale and offset metadata. It archives per-site scene and acquisition time plus the STAC catalog responses. [Copernicus Sentinel-2 products](https://sentiwiki.copernicus.eu/web/s2-products) · [Earth Search collection](https://earth-search.aws.element84.com/v1/collections/sentinel-2-c1-l2a)
- The elevation covariate is a static surface model. Source tiles were sampled in their geographic CRS. The training code excludes team, raw row keys, scene metadata, year, dates and EC-derived fields. [Copernicus DEM registry](https://registry.opendata.aws/copernicus-dem/)
- The Satkhira overlay uses a pinned public district polygon. Matching counts support a plausible subset construction but cannot establish author-selected records, input values or fold identity. [Boundary source](https://github.com/wmgeolab/geoBoundaries/tree/9469f09/releaseData/gbOpen/BGD/ADM2) · [2026 preprint](https://arxiv.org/html/2604.23127v1)
- The pasted IEEE template, housing-workflow example image and prior DOCX were unavailable. The manuscript uses the standard IEEEtran conference class and an original workflow diagram.
